# lukashop — 부품 호환성을 검증하는 컴퓨터 판매 사이트

조립 PC와 부품을 파는 쇼핑몰입니다. 일반 이커머스와 다른 점은 **견적짜기(PC Builder)** 하나입니다.
부품을 고르는 즉시 소켓·메모리 규격·물리적 크기·전력 여유를 검사해 조립 전에 문제를 알려줍니다.

> ⚠️ 포트폴리오 목적의 데모입니다. 실제 판매·결제가 이루어지지 않으며 상품과 가격은 가상의 데이터입니다.

**현재 단계: 뼈대(2단계).** 목데이터로 화면과 도메인 로직을 세운 상태이고, DB·인증·결제는 아직 없습니다.

## 만든 것

| 화면 | 경로 | 내용 |
|---|---|---|
| 메인 | `/` | 히어로 슬라이더, 퀵액션, 카테고리별 상품 섹션, 후기 |
| 전체 상품 | `/products` | 검색·분류·정렬·페이지네이션 (상태를 URL 쿼리에 둠) |
| 상품 상세 | `/products/[slug]` | 스펙 표, 장바구니 담기, 같은 분류 상품 |
| 카테고리 | `/category/[slug]` | 분류별 목록 12종 |
| **견적짜기** | `/builder` | **호환성 검증 엔진 + 견적 공유 링크** |
| 장바구니 | `/cart` | 수량 조정, 배송비 계산 |

정적 페이지 63개가 빌드 시점에 생성됩니다.

## 견적짜기 — 이 프로젝트의 핵심

`lib/builder/compatibility.ts`는 React도 네트워크도 모르는 **순수 함수**입니다.
구성(`BuildSlots`)을 넣으면 문제 목록(`Issue[]`)이 나옵니다. 그래서 테스트가 붙습니다.

검사하는 규칙 11가지:

| # | 규칙 | 수준 |
|---|---|---|
| 1 | CPU ↔ 메인보드 소켓 일치 | 오류 |
| 2 | 메모리 ↔ 메인보드 DDR 규격 일치 | 오류 |
| 3 | 메인보드 폼팩터가 케이스 지원 규격에 포함 | 오류 |
| 4 | 그래픽카드 길이 ≤ 케이스 한계 | 오류 |
| 5 | 쿨러 높이 ≤ 케이스 한계 (수랭 제외) | 오류 |
| 6 | 쿨러가 CPU 소켓을 지원 | 오류 |
| 7 | 쿨러 감당 발열 ≥ CPU TDP | 경고 |
| 8 | 총 소비전력 × 1.3 ≤ 파워 정격 | 경고 |
| 9 | 그래픽카드 제조사 권장 파워 ≤ 파워 정격 | 경고 |
| 10 | CPU ↔ GPU 성능 등급 차 2 이상 (병목) | 경고 |
| 11 | 내장 그래픽 없는 CPU + 그래픽카드 없음 | 경고 |

**오류와 경고를 나눈 이유**: 소켓이 안 맞으면 물리적으로 조립이 안 되지만, 파워가 빠듯한 건
사용자가 감수하고 살 수 있는 문제입니다. 전자만 장바구니 담기를 막습니다.

**빈 슬롯은 오류로 보고하지 않습니다.** 부품을 하나씩 채우는 중에 붉은 배너가 계속 떠 있으면
아무도 읽지 않게 됩니다. 각 규칙은 필요한 슬롯이 모두 채워졌을 때만 판정합니다.

### 견적 공유

원래 설계는 DB에 저장하고 `share_token`을 발급하는 방식인데, 뼈대 단계에는 서버가 없습니다.
대신 구성을 쿼리스트링에 실어 `?cpu=...&gpu=...` 링크로 만듭니다.
서버가 붙으면 이 링크를 그대로 저장 요청의 입력으로 쓸 수 있어 버려지는 코드가 아닙니다.

URL로 들어온 slug는 신뢰하지 않고, 카탈로그에 있으면서 그 슬롯에 맞는 부품일 때만 받아들입니다.

### 몇 가지 판단

**스펙을 key-value가 아니라 타입 있는 판별 유니온으로 뒀습니다.**
실제 DB 스키마(`product_specs`)는 key-value 텍스트 테이블이지만, 호환성 엔진이
`cpu.spec.socket`처럼 필드에 직접 접근해야 합니다. key-value로는 매번 문자열을 찾아
파싱해야 하고 오타가 컴파일 타임에 안 걸립니다. DB를 붙일 때 어댑터를 한 겹 끼웁니다.

**장바구니에 가격을 저장하지 않습니다.** slug와 수량만 담습니다. 가격을 함께 저장하면
그 값이 곧 낡고, 낡은 가격으로 결제 금액을 계산하는 사고로 이어집니다.
금액 스냅샷은 주문을 만드는 시점에 서버가 찍습니다.

**금액은 전부 원 단위 정수입니다.** `NUMERIC`/`FLOAT`을 쓰지 않습니다 — 부동소수 오차 때문입니다.

**localStorage는 `useSyncExternalStore`로 구독합니다.** `useEffect`에서 읽어 상태로 복사하는
방식은 "외부 시스템의 값을 React 상태로 복사"하는 안티패턴이고, 다른 탭에서 담은 것도 못 따라옵니다.

**카드 전체 클릭은 stretched link로 구현했습니다.** 카드를 `<a>`로 감싸면 내부 링크가
중첩 앵커가 되어 규격 위반입니다. 제목 링크를 `::after`로 카드 크기만큼 늘렸습니다.

## 기술 스택

- **Next.js 16** (App Router) + TypeScript
- **CSS Modules + CSS 변수 토큰** — Tailwind 없음. 색·간격을 하드코딩하지 않습니다
- 다크 테마 단일. 한글 가독성을 위해 본문 15px / 행간 1.75 / `word-break: keep-all`
- 목데이터. DB·인증·결제 없음

현재는 서버가 필요 없어 `output: 'export'`로 정적 내보내기를 합니다.
결제를 붙이는 시점에 이 설정을 빼고 배포 방식을 다시 정합니다.
